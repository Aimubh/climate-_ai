On air

Straight answers

What people ask first.

Is this real data?

Yes. Every number on this page comes from Open-Meteo's public feed, which needs no key and refreshes every 15 minutes. India's official station network, 1,729 IMD stations, is the next source once access is granted.

How accurate is it?

We publish the average error on the last 365 days the model never saw, right under the forecast, next to the plain carry-today-forward baseline. A number you cannot check is not a forecast.

Does it work for my town?

Any point in India with a latitude and longitude. No grid box, no nearest big city.

Can I use it in my own app?

Yes. The code is open source under the MIT license. Run it, fork it, ship it.
